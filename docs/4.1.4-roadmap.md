# Roadmap

The platform is a server-owned, multi-client Scrabble service.

The platform has pluggable engines ([4.1.1](4.1.1-architecture.md)).

## Where the work is now

Drawn from the issues, in [4.1.5 Work in progress](4.1.5-work-in-progress.md) —
kept separate so a reader can leave it open in a browser.

## Minimum viable product (MVP)

The MVP is built:

- Server-owned game state and rule enforcement
- Human-vs-human, human-vs-engine and engine-vs-engine games, with
  engine-vs-engine tests
- One stable engine interface for plug-ins (`GameEngine`; `GreedyEngine` is the
  reference implementation)
- Shared pure rules library for legality and score previews
- Game creation, join, start, resign, pass, exchange tiles and move history
- Server-side scoring and legality checks
- Web and desktop clients
- Basic reconnect support: `GET /games/{id}` reloads the full state, and "stay
  logged in" restores a session
- Deterministic tests for move legality, scoring and endgame flow
  (`cargo test --workspace`)
