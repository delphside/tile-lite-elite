# Rules engine modules and types

The modules and types of the `rules-shared` crate; behaviour is in 4.2.1.

[4.2.1](4.2.1-rules-engine.md) owns the design. This page names where each
piece lives, in `crates/rules-shared/src/`.

## Modules in rules-shared

The crate root re-exports the types below. The modules, with the section of
[4.2.1](4.2.1-rules-engine.md) that owns each one's behaviour:

| Module | Holds | Behaviour |
| --- | --- | --- |
| `model` | rules data and move types: [Rules and letters](#rules-and-letters), [Moves](#moves) | [Structure](4.2.1-rules-engine.md#structure) |
| `board` | `BoardState` and its cells | [Structure](4.2.1-rules-engine.md#structure) |
| `cache` | `RuleCache`: cross-checks, anchor flags, line extents, and their recomputation | [Cross-checks](4.2.1-rules-engine.md#cross-checks), [Anchors](4.2.1-rules-engine.md#anchors), [Cache update](4.2.1-rules-engine.md#cache-update) |
| `validate` | `GameState`, `RulesPosition`, `RulesEngine`, `MoveValidator`: preview, validation, scoring and `apply_move` | [Move validation](4.2.1-rules-engine.md#move-validation), [Scoring](4.2.1-rules-engine.md#scoring) |
| `generate` | `MoveGenerator` and the enumeration methods on `RulesEngine` | [Move enumeration](4.2.1-rules-engine.md#move-enumeration) |
| `dictionary` | the `Dictionary` and `PrefixCursor` traits, `WordListDictionary`, the word-list texts, the four statics, `dictionary_by_name`, `alphabet_by_name` | [Dictionary structure](4.2.1-rules-engine.md#dictionary-structure) |
| `tiered` | `TieredDictionary` and its cursor and packing types | [Dictionary structure](4.2.1-rules-engine.md#dictionary-structure) |
| `wordlists` | the denylist and greylist: parsing and whole-word matching | [4.3.5](4.3.5-word-lists-and-dictionaries.md) |
| `format` | `format_move_error`: the player-facing text of a `MoveError`, shared by the server's submission path and the client's preview | none: the wording is the function |
| `score` | `MoveScorer`, a trait with one default method returning a zero `MoveScore`; nothing implements or calls it | none: scoring is in `validate` |

## Rules and letters

All in `model`.

| Type | Holds |
| --- | --- |
| `VariantRules` | one edition's name, language, alphabet, letter values, tile distribution, blank count, rack size, board size, bingo bonus and 225 premiums; built by `official`, `north_american`, `german`, `spanish` and looked up by `by_name` |
| `Alphabet` | the ordered graphemes of an edition; `Letter(i)` is the *i*th; `to_letter` resolves one tile's text exactly |
| `Grapheme` | one tile's text: `Single(char)` or `Double(char, char)` for a digraph |
| `Letter` | an index into the alphabet |
| `LetterMask` | `u64`, one bit per letter; helpers `mask_contains`, `mask_insert`, `mask_remove`, `mask_is_empty`, `mask_is_full`; `FULL_LETTER_MASK` |
| `MAX_ALPHABET_SIZE` | 64: the length of every letter-indexed array (`letter_values`, `tile_distribution`, `Rack::counts`, `score_by_letter`); a compile-time assertion ties it to the width of `LetterMask` |
| `Score` | `i16` |
| `Tile` | `Letter(Letter)` or `Blank { acting_as: Option<Letter> }` |
| `Rack` | `counts` by letter and `blanks`; `Copy` |
| `Premium` | `Blank`, `DoubleLetter`, `TripleLetter`, `DoubleWord`, `TripleWord`, with `letter_multiplier` and `word_multiplier` |
| `Direction` | `Horizontal` or `Vertical`; `-d` is the other |
| `Position` | `x` and `y`, zero-based; displays as column letter and row number |

Two traps:

- `Letter`'s `From<char>` subtracts `b'A'`, so it is right only for an
  alphabet that runs A to Z in order; convert text with `Alphabet::to_letter`
- the browser client fetches its word list and builds the dictionary itself,
  which needs the edition's alphabet: `alphabet_by_name` is available on wasm,
  the dictionaries are not

## Moves

All in `model`; the checks and errors are in
[Move validation](4.2.1-rules-engine.md#move-validation).

| Type | Holds |
| --- | --- |
| `MoveCandidate` | `start`, `direction` and `tiles` |
| `TilePlacement` | a `tile` and its `offset` from `start` |
| `MovePreview` | `legal`, `main_word`, `total_score`, `cross_words` and the `error` |
| `CrossWordPreview` | a cross word's `pos`, `word` and `score` |
| `MoveScore` | `total`, `main_word_score`, `cross_word_score` and `bingo_bonus` |
| `ValidatedMove` | the candidate, its preview and its score |
| `MoveError` | `InvalidMove`, `InvalidWord(words)`, `InvalidPosition`, `InvalidDirection`, `TilesDoNotFit`, `TilesDoNotConnect`, `OpeningMoveTooShort` |

## Board and cache types

The board holds no derived data; the cache is rebuilt from the board, the
rules and the dictionary ([Structure](4.2.1-rules-engine.md#structure)).

| Type | Module | Holds |
| --- | --- | --- |
| `BoardState` | `board` | `cells`: 225 `BoardCell`; `new(rules)` lays out the premiums; `get`, `get_mut`, `set`, `filled_letter` |
| `BoardCell` | `board` | `Empty(EmptyCell)` or `Filled(FilledCell)` |
| `EmptyCell` | `board` | its `premium` |
| `FilledCell` | `board` | its `letter` and `is_blank` |
| `RuleCache` | `cache` | `cells`: 225 `CachedCell`; `extents` |
| `CachedCell` | `cache` | a `CrossCheck` for `horizontal` and for `vertical`; `anchor_flags` |
| `CrossCheck` | `cache` | `Unconstrained` or `Constrained(ConstrainedCrossCheck)`; `allows`, `perpendicular_score`, `forms_cross_word` |
| `ConstrainedCrossCheck` | `cache` | `allowed_mask`, `score_by_letter` and `blank_score` |
| `AnchorFlags` | `cache` | `horizontal_anchor` and `vertical_anchor` |
| `LineExtents` | `cache` | `row_left`, `row_right`, `col_top`, `col_bottom`: 225 `u8` each |

## Engine types

All in `validate` unless stated.

| Type | Holds |
| --- | --- |
| `GameState` | a `BoardState` and its `RuleCache`; `new`, `from_board`, `position`, `position_with_rack` |
| `RulesPosition` | borrowed `board`, `cache` and an optional `rack`: the state the validator reads |
| `RulesEngine` | borrowed `rules` and `dictionary`; no state of its own |
| `MoveValidator` | trait with `preview_move` and `validate_move`; implemented for `RulesEngine` over a `RulesPosition` |
| `MoveGenerator` (`generate`) | trait with `enumerate_legal_moves`; implemented for `RulesEngine` over a `GameState` and a `Rack` |

`RulesEngine` methods:

| Method | Does |
| --- | --- |
| `preview_move`, `validate_move` | take a `RulesPosition` |
| `preview_game_move`, `validate_game_move` | take a `GameState` and an optional rack |
| `apply_move`, `apply_move_to_game` | write a `ValidatedMove` to the board and update the cache; return `Result<(), MoveError>` |
| `enumerate_legal_moves`, `enumerate_legal_multi_tile_moves` | moves with up to `rack_size` tiles |
| `enumerate_legal_single_tile_moves` | moves with one tile |

## Dictionary types

| Type | Module | Holds |
| --- | --- | --- |
| `Dictionary` | `dictionary` | `is_word`, `root_cursor`, `allowed_letters` |
| `PrefixCursor` | `dictionary` | `advance(letter, alphabet)`, `None` when no word continues |
| `WordListDictionary` | `dictionary` | a sorted word list with a `SortedPrefixCursor`; the oracle for the differential tests of `TieredDictionary`, not used in production |
| `SOWPODS`, `ENABLE2K`, `GERMAN`, `SPANISH` | `dictionary` | lazily built `TieredDictionary` statics, on non-wasm targets; `build_all_dictionaries` builds all four |
| `TieredDictionary` | `tiered` | arena, dense table and sparse index; `from_word_list`, `contains`, `root`, `advance`, `word_count`, `resident_bytes` |
| `Cursor`, `Step` | `tiered` | a position in the walk, and the result of one `advance` (`cursor`, `is_word`) |
| `TieredCursor` | `tiered` | a `Cursor` with its dictionary: the `PrefixCursor` of `TieredDictionary` |
| `Child`, `PackedChild` | `tiered` | what an edge points at, and its `u32` packing; the doc comment on `PackedChild` has the bit layout |
| `MAX_LEAF_WORDS`, `MAX_SCAN_WORDS` | `tiered` | 64 and 32: the largest unindexed group, and the largest group scanned rather than bisected |
