# Stems the greylist generator expands, and the words it must not catch.
#
# Nothing here is generated: this file is the judgement, which is why it is
# committed and reviewed rather than recomputed. See
# docs/3.5-word-lists-and-dictionaries.md, "Generating the greylist".
#
# REVIEWED IN FULL by the owner, 2026-08-12. ESCORT* and DOMINATION* struck as
# ordinary words; everything else kept, including the contested rows — WELCH*,
# SODOM*, NONG, the GYP family and the MONGOL family — and TWINKIE*, on the
# grounds that a trademark is not a competing legitimate sense.
#
# So every entry below is a decision, not a proposal. Adding one is cheap and
# safe; removing one lets the bot play those words, so it wants the same look
# these got.
#
# WHY THIS FILE EXISTS. rustrict catches most of what the greylist wants, but
# its recall gaps are arbitrary: it flags NEGROES, NEGROID and NEGROIDS but not
# NEGRO; POOFTER but not POOF or POOFTAH; POONTANG but not POON; SMUTTY but not
# SMUT; and misses MONG entirely. A base word slipping through while its
# inflections are caught is exactly the case the greylist exists to prevent.
#
# SYNTAX
#   WORD      grey this word, exactly
#   PREFIX*   grey every dictionary word starting with PREFIX
#   !WORD     never grey this word, whatever else matched it
#
# ERR LONG. A wrongly greyed word is one the bot declines to play, which nobody
# can observe; a missed one is a bot playing something a child should not read.
# The two are not comparable, so entries below lean towards greying. Striking an
# entry is cheap — that is what this draft is for.
#
# ENGLISH ONLY. Applies to sowpods and enable2k. German and Spanish are out of
# scope: neither can be reviewed by somebody who does not speak the language,
# which is the blocker rather than the sourcing.
#
# The word counts in comments are what each line adds beyond what rustrict
# already flags, measured against sowpods (267,752 words).
